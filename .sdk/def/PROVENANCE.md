## Why this SDK exists

It is on the admin repository's **vergleich** list: SDKs built with the Voxgig
toolchain to compare it with the generators on voxgig.com/sdk/comparisons, one
API per generator. This one is compared with **Fern**.

- **Compared with:** VapiAI/server-sdk-typescript, `@vapi-ai/server-sdk` 2.0.1, generated by Fern (`.fern/metadata.json`, fern-typescript-sdk 3.63.0). Vapi also ships Fern SDKs for Python, Go, Ruby, C#, PHP and Swift.
